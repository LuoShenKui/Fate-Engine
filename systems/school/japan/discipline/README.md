# Discipline

Discipline 将校规、学生行为和制度后果连接起来。

## Common Incidents

- 迟到
- 无故缺席
- 早退
- 课堂扰乱
- 作业长期未交
- 考试作弊
- 打架
- 欺凌
- 破坏财物
- 禁止携带物
- 制服或校规违反
- 未经允许进入区域
- 社团违规
- 校外问题影响学校

具体规则由学校模板配置。

## Incident Flow

Behavior
→ Witness / Evidence
→ Report
→ Investigation
→ Student Explanation
→ Teacher / Student Guidance Decision
→ Guardian Contact
→ Punishment / Warning / No Action
→ Permanent Record
→ Future Consequences

## Possible Consequences

支持口头提醒、书面警告、反省文、补习留校、社团限制、校内处分、停学、转班、退学建议和警察介入。

不同学校允许的处分范围不同，因此必须参数化。

## Causality

Cheating
→ Grade Invalidated
→ Teacher Trust Down
→ Parent Meeting
→ Club Participation Restricted
→ Student Misses Competition
→ Club Relationship Changes

处分不是状态标签，而是一条后续因果链。
