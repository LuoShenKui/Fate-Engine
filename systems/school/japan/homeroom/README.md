# Homeroom & Class Life

班级是日本校园世界最重要的社会单位之一。

## Class State

- Grade
- Class Number
- Homeroom Teacher
- Students
- Seat Map
- Class Officers
- Duty Roster
- Class Reputation
- Current Projects
- Shared Budget
- Rules

## Daily Homeroom

Morning Homeroom 处理出勤、公告、当日日程、收文件、临时通知和纪律提醒。

End-of-day Homeroom 处理第二天通知、活动安排、值日、失物、学园祭或体育祭准备和教师谈话。

## Seating

座位不是视觉数据。它会影响课堂交流、作弊机会、朋友形成、冲突、教师关注和玩家可接触人物。换座位应该是真实事件。

## Class Roles

默认可配置班长、副班长、学习职责、体育职责、文化祭执行委员、美化清扫职责和生徒会代表。

## Cleaning

清扫是集体行为：分配区域、成员参与、完成质量和教师反馈都会进入关系与记忆系统。
