# Academics

课堂必须是真正的世界行为，而不是“时间快进”。

## Academic Entities

- Subject
- Course
- ClassSection
- Teacher
- Student
- Lesson
- LearningUnit
- Assignment
- Quiz
- Exam
- GradeRecord
- AttendanceRecord

## Lesson Lifecycle

Teacher arrives
→ Attendance
→ Lesson starts
→ Learning Unit taught
→ Student participation
→ Questions / interruptions
→ Knowledge state changes
→ Homework / task assigned
→ Lesson ends

玩家和 NPC 都可以正常听课、迟到、旷课、睡觉、做别科作业、回答问题、提问、被点名、帮同学、扰乱课堂、临时离开或与老师争论。

## Learning State

不模拟每一个公式的思考过程，但必须模拟真实学习结果。

每个学生至少拥有：

- Knowledge Mastery
- Subject Aptitude
- Interest
- Study Habit
- Concentration
- Fatigue
- Attendance
- Homework Completion
- Exam Performance

示例：

连续旷课
→ Algebra Mastery 落后
→ 作业困难
→ 考试成绩下降
→ 班主任关注
→ 家长面谈
→ 社团活动可能受限制

## Exams

支持小测验、单元测验、期中、期末、补考、模拟考试和升学相关考试。

成绩不是单一随机数，应受到知识掌握、复习、天赋、专注、健康、睡眠、压力、作弊或帮助以及有限随机性的共同影响。

作弊会连接 Discipline System。

## Teachers

教师也是 Character，具有教学能力、课程熟悉度、严格程度、学生印象、疲劳、偏好、情绪和学校职责。

教师缺勤必须产生 Substitute Teacher、Self-study、Class Swap 或 Cancellation 等结果。
