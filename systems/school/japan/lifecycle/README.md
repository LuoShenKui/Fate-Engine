# Student Lifecycle

Lifecycle 管理学生从进入学校到离开学校的完整制度过程。

## Admission / New Student

Enrollment
→ Student Record
→ Grade Assignment
→ Class Assignment
→ Homeroom Assignment
→ Seat Assignment
→ Entrance Ceremony
→ Orientation
→ Club Recruitment
→ Normal School Life

新生欢迎可以包含入学式、校长致辞、在校生欢迎、校规介绍、校园介绍、第一次 Homeroom、自我介绍、教材文件发放和社团招新。

这些都应该产生真实世界状态。

## Transfer Student

Transfer Approved
→ School Record Imported
→ Grade / Class Decision
→ Homeroom Teacher Notification
→ Seat Allocation
→ Arrival Date Scheduled
→ Teacher Introduction
→ Self Introduction
→ First-impression Relationships
→ Club / Friendship / Rumor Reactions

转学生可以在学期中任意日期进入。

原学校成绩、处分、社团经历和家庭背景可以根据世界设定部分继承。

## Promotion

Academic Review
→ Attendance Review
→ Promotion Decision
→ Record Archive
→ New Grade
→ New Class Assignment
→ New Homeroom / Seat / Teachers

## Graduation

毕业资格检查、毕业式、社团引退、生徒会交接、进路结果和 Alumni Identity 都属于生命周期。

毕业不会删除 Character，只会改变身份和日程。
