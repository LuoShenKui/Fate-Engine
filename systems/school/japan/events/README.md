# School Events

学校行事是年度日历中的一等事件。

## Ceremonial Events

- 入学式
- 始业式
- 终业式
- 修了式
- 毕业式
- 新生欢迎
- 表彰
- 社团与生徒会交接

## Cultural Events

- 文化祭 / 学园祭
- 合唱
- 演剧
- 展览
- 文化发表
- 社团成果展示

## Culture Festival Lifecycle

Festival Announced
→ Student Council Rules
→ Class / Club Proposal
→ Approval
→ Budget
→ Role Assignment
→ Preparation Weeks
→ Material Purchase
→ Rehearsal / Construction
→ Festival Day
→ Cleanup
→ Accounting
→ Evaluation / Consequences

班级企划可以是 Cafe、Haunted House、Exhibition、Stage Show、Game Booth、Food Stall 或作品专属活动。

企划必须受到预算、房间、安全、校规、人手、时间和教师审批约束。

## Sports / Safety Events

- 体育祭 / 运动会
- 球技大会
- 健康诊断
- 避难训练
- 防灾训练
- 交通安全
- 防犯指导

## Travel Events

- 远足
- 修学旅行
- 宿泊活动
- 校外学习

旅行会临时改变整个 NPC 日程与地点。

## Parent / Public Events

- 授业参观
- 保护者会
- 三者面谈
- 学校公开日

## Event Output

任何 Event 都应该输出 Attendance、Participation、Role Performance、Relationship Changes、Reputation、Budget Changes、Discipline Incidents、Memories 和 Future Hooks。

因此“学园祭告白”“体育祭受伤”“修学旅行走失”等玩法可以从底层系统自然发生。
