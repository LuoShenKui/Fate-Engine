# Clubs

社团系统必须能够长期独立运转。

## Club State

- ClubId
- Name
- Type
- AdvisorTeacher
- President
- VicePresident
- Members
- Applicants
- ActivitySchedule
- Facilities
- Equipment
- Budget
- Rules
- Reputation
- CompetitionCalendar
- Goals

## Club Types

支持体育系、文化系、艺术系、科学系、游戏兴趣系和非正式同好会。世界包可以增加作品专属社团。

## Annual Lifecycle

April Recruitment
→ Trial Participation
→ Join / Reject
→ Regular Activities
→ Events / Competitions
→ Culture Festival / Tournament
→ Senior Retirement
→ Officer Election
→ Handover

## Membership

加入社团不是一个 bool，需要考虑入部申请、试体验、容量、顾问许可、时间、过去处分、技能、人际关系和是否兼部。

## Daily Activity

社团活动消耗时间、体力、金钱、场地和器材，同时提升技能、关系、声望和归属感。

## Senpai / Kouhai

年级差可以形成指导、权威、崇拜、压力、冲突和交接，但它不是强制人格规则，只是组织关系和文化参数。

## Competitions

Training
→ Selection
→ Team Formation
→ Match
→ Result
→ Reputation / Motivation / Relationship

比赛结果必须影响人物目标和社团未来。
